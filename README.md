# Object Oriented Programming (CEUE203) - Java Practicals

This repository contains solutions for the Java Programming practical coursework (Semester 3).

## Directory Structure

```text
JAVA/
├── lab1/ ... lab14/          # Weekly lab practicals (Practicals 1 to 14)
│   ├── pra1/                 # Problem 1
│   └── pra2/                 # Problem 2
└── README.md
```

## Lab Summary

- **lab1**:
  - `pra1`: Vending Machine using enum `Coin` and switch expressions.
  - `pra2`: Toll Booth record `Vehicle` with toll counters.
- **lab2**:
  - `pra1`: Smart Thermostat with constructor chaining and limits.
  - `pra2`: Cinema Show booking and cancellation tracking.
- **lab3**:
  - `pra1`: Distinct Points overriding `equals()`, `hashCode()`, and `toString()`.
  - `pra2`: Duplicate Card detection using `Card` and `equals()`.
- **lab4**:
  - `pra1`: Password Strength evaluator with regex and string checks.
  - `pra2`: Chat Log filter with `split()` and `StringBuilder`.
- **lab5**:
  - `pra1`: Abstract `Shape` hierarchy (`Circle`, `Rectangle`, `Triangle`).
  - `pra2`: Abstract `Employee` payroll (`FullTime`, `PartTime`, `Intern`).
- **lab6**:
  - `pra1`: `Switchable` interface, default methods, and lambda `SwitchPolicy`.
  - `pra2`: `Notifier` functional interface and `Urgent` marker interface.
- **lab7**:
  - `pra1`: Custom annotations `@NotBlank` and `@MaxLength` with reflection validator.
  - `pra2`: Custom `@Run` annotation test runner using reflection.
- **lab8**:
  - `pra1`: Guarded Calculator with custom `DivideByZeroException` and `finally`.
  - `pra2`: Warehouse stock issue with custom checked exceptions.
- **lab9**:
  - `pra1`: Counter Race comparing unsynchronized vs. synchronized increments.
  - `pra2`: Seat Booking Race demonstrating thread safety with `synchronized`.
- **lab10**:
  - `pra1`: Thread Pool Runner using `ExecutorService` (fixed pool of 3).
  - `pra2`: Producer-Consumer pattern using `wait()` and `notify()`.
- **lab11**:
  - `pra1`: Object serialization and deserialization with `transient` fields.
  - `pra2`: NIO Path/Files log analyzer.
- **lab12**:
  - `pra1`: Word frequency counter with `HashMap` and `Comparator`.
  - `pra2`: Unique visitors tracking with `HashSet` and `LinkedHashSet`.
- **lab13**:
  - `pra1`: Generic containers `Box<T>` and `Pair<A, B>`.
  - `pra2`: Bounded type generic method for numeric averages.
- **lab14**:
  - `pra1`: Layered Student Management Application with `ArrayList` and menu.
  - `pra2`: Serializable record persistence.
